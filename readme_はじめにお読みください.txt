■概要
王宮騎士のロレンチアの結末は、リスクヘッジによって決まる。
無事に4日目を終えるまで…すべてのアクシデントを回避すべし。

全16イベント(エンディングを除く)


■遊び方
本作は戦闘やレベル上げ要素のないイベント回収型ゲームです。
上下左右の矢印キーとZ、Xキー、もしくはマウス操作のみで遊べます。
(メッセージはAキーでオート送り、Sキーでスキップできます。)
イベントのテキスト量は少なめです、あらかじめご了承ください。
